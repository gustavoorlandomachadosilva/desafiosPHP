# Desafios e Estudos em PHP
#### Vi esses desafios no GitHub da Ester Farias (Acesse:https://github.com/Ester-Farias/66-Exercise-PHP) decidi resolvê-los com minha forma de pensar utilizando PHP.
#### PHP 8.0.28

## Seguem os desafios:
1✔ Crie uma página PHP que imprima "Olá, Mundo!". <br>
2✔ Declare variáveis para armazenar seu nome e idade e imprima na tela <br>
3✔ Declare duas variáveis, atribua valores a elas e depois imprima a soma. <br>
4✔ Faça um programa que verifique se um número é par ou ímpar.<br>
5✔ Crie uma lista de cinco frutas e as exiba na tela.<br>
6✔ Crie um array associativo com informações de uma pessoa (nome, idade, cidade, etc.) e imprima cada valor.<br>
7✔ Crie uma função para calcular a área de um quadrado.<br>
8✔ Escreva um loop que imprima os números de 1 a 10<br>
9✔ Calcule a média de três números.<br>
10✔ Crie uma função que receba uma string e retorne o número de caracteres.<br>
11✔ Utilize a função explode para separar uma frase em palavras e imprima cada palavra em uma linha.<br>
12✔ Faça um script que substitua todas as ocorrências de uma palavra em uma frase por outra palavra.<br>
13✔ Crie um array com números aleatórios e encontre o maior valor.<br>
14✔ Escreva uma função que receba um array de números e retorne a média.<br>
15✔ Utilize um loop para imprimir os números pares de 2 a 20.<br>
16✔ Crie uma função que receba um número e retorne se é positivo, negativo ou zero.<br>
17✔ Faça uma pesquisa em um array e retorne o índice de um elemento específico.<br>
18✔ Crie uma função para verificar se uma palavra é um palíndromo.<br>
19✔ Utilize um loop para imprimir os valores de um array em ordem reversa.<br>
20✔ Crie um array associativo com informações de produtos (nome, preço, quantidade em estoque) e imprima uma tabela HTML com esses dados.<br>
21✔ Manipule datas: obtenha a data atual e imprima-a no formato "dia/mês/ano".<br>
22✔ Implemente um programa de tabuada.<br>
23✔ Crie uma função que calcule o fatorial de um número.<br>
24✔ Crie um contador de caracteres.<br>
25✔ Implemente uma função para converter uma temperatura de Celsius para Fahrenheit e vice-versa.<br>
26✔ Crie um gerador de senhas aleatórias com diferentes níveis de complexidade.<br>
27✔ Crie um formulário HTML com campos de nome, email e senha. Ao enviar o formulário, processe os dados com PHP e imprima na tela.<br>
28✔ Faça um formulário que permita o envio de um arquivo. Trate o arquivo no lado do servidor para garantir que seja do tipo esperado e exiba informações sobre ele.<br>
29✔ Faça uma requisição HTTP para obter dados de uma API (por exemplo, a API do GitHub).<br>
30✔ Crie um arquivo de texto com algumas linhas e, em seguida, escreva um script PHP para ler e imprimir o conteúdo desse arquivo. <br>
